# 多語系文字比對

抓下遊戲裡所有的字句（頁面文字、共用語系檔、圖片上的字），並和 Excel 翻譯表比對是否一致。

## 啟動

需要 Node.js 18 以上，不用另外安裝任何套件。

- 雙擊 `start.bat`，或
- 在這個資料夾執行 `npm start`

接著打開 http://localhost:5178 。

### 分享給同網路的同事（同事不用安裝）

1. 在你的電腦雙擊 `start-share.bat`。
2. 黑色視窗會列出網址，例如 `http://192.168.53.14:5178`，把它傳給同事。列出多個時，通常是開頭和同事電腦 IP 相同的那個（同事可在命令提示字元輸入 `ipconfig` 查自己的 IP）。
3. 第一次執行時 Windows 防火牆若跳出詢問，勾「私人網路」後按「允許存取」。
4. 同事用瀏覽器打開那個網址，用法和你一樣；每個人的上傳檔案、比對結果、OCR 都在自己的瀏覽器裡，互不影響。

注意：
- 你的電腦要開著，黑色視窗不能關；關掉網站就停止。
- 公司網路的 IP 可能會變，下次啟動時以視窗上顯示的為準。
- 同事打不開時，多半是防火牆擋住，或公司 Wi-Fi 不允許電腦之間互連（可改用有線網路，或請 IT 協助）。

## 使用方式

1. **參考文件**：上傳 Excel（例如 `FS - Version 137-EUR (Verified).xlsx`），**可以一次選多個檔案**，之後也能按「＋ 新增 Excel」再加。每個分頁是一款遊戲，第一列是語言標題（EN、ITALY、Thai、TH (revised)、Japan…）。
   - 有 `(revised)` 欄時，以修訂版為準；沒有修訂內容的列才用原欄位。
   - **上傳的每個檔案都會用到**：每個檔案用和遊戲同名的分頁（「FS - Tree of Wild」和「Tree of Wild」視為同一款）；檔案裡沒有同名分頁、但只有一個分頁時，就用那一頁。例如 EUR 檔和 ASIA 檔的語言會合併。
   - 每個檔案旁邊會顯示用了哪個分頁、幾筆；顯示「未使用」時，到下方勾選要用的分頁即可。
   - **主要檔案**：有多個檔案時，在檔案前勾選「主要」。遊戲每一句先用主要檔案比對；主要檔案沒有對應的句子時，才依序用其他檔案（答案旁會標「備用」）。即使其他檔案有完全一樣的句子，只要主要檔案有相近的句子，就以主要檔案為準。
   - 語言標題可以是英文或中文，例如 EN / English / 英文、Thai / 泰文、Indonesian / 印尼文、TH (revised) / 泰文（修訂）。
   - 「加入其他分頁」可再勾選別的分頁一起比對，例如共用字串的分頁。
   - 同一句英文、同樣翻譯出現在多個檔案時只比對一次，並註明「也在：哪個檔案第幾列」；**翻譯不同時兩列都會比對，並標示「另一份 Excel 的翻譯不同」**。
   - 同名的檔案兩份都會保留，第二份顯示為「檔名 (2)」；要換新版本時，把舊的那份「移除」即可。
2. **比對對象**，四種方式擇一：
   - **遊戲清單**：預設讀取 `https://qa-go.object1.net/touch/fsnew/list.jsp`，會依分頁名稱自動選到遊戲（例如「FS - Tree of Wild」→ Tree of Wild）。「內容」預設是**全部字句**，會抓：
     - **頁面**：paytable、help 等 HTML 的文字
     - **文字資料**：共用語系檔裡這款遊戲的字串（例如 `TXT_SLOT_TW02_WILD`，點符號時的說明）
     - **圖片 OCR**：遊戲內烤在圖片上的字（開場頁、上方提示條、免費遊戲、大獎、按鈕、paytable 圖片…），用 OCR 辨識
     語言可選「Excel 內的語言」或「全部語言」。
   - **貼上連結**：一行一個頁面網址，依網址中的 `_th_TH.` 等判斷語言。
   - **上傳頁面檔**：HTML 或 TXT，依檔名判斷語言（可手動改）。
   - **貼上文字**：直接貼一段文字比對。
3. 按 **開始比對**（沒上傳 Excel 時按鈕是「抓取字句」）。結果有兩個分頁：
   - **遊戲字句（逐句比對）**（預設）：遊戲裡的**每一句**依出現順序列出，旁邊是 Excel 的正確答案和結果；Excel 沒有的句子標「Excel 未列出」。圖片字句附縮圖，OCR 認錯的字可以直接改，改完會立刻重新比對
   - **依 Excel 列**：Excel 每一列在遊戲裡的對應文字；「遊戲找不到」= Excel 有、遊戲裡沒有
4. **匯出 Excel 報告**：含總覽、「全部字句對照」（每一句一列、每種語言一欄），以及每種語言一張逐句比對表（遊戲字句 + Excel 正確答案 + 來自哪個 Excel 檔案/分頁/第幾列；最後附上 Excel 有但遊戲找不到的句子）。

## 比對規則：整句對整句

- 遊戲的**一整句**對 Excel 的**一整句**：Excel 的短句只是包含在遊戲某行裡（例如「Free Spins」出現在一段長說明中），不算對到。
- 兩種情況會合併比對，但文字必須完全對得上：遊戲把 Excel 相鄰的兩列寫在同一行，或把 Excel 的一句拆成兩行。
- 只差數字的短標籤（例如「Tier 1」和「Tier 2」）視為不同句子，不會拿來互相比對。
- `[WILD]` 這類佔位符最多代表約 12 個字（一個符號名稱）。

## 結果怎麼看

| 狀態 | 意思 |
| --- | --- |
| 相符 | 遊戲裡有完全一樣的文字（圖片文字不分大小寫與空白） |
| 仍為舊翻譯 | Excel 有修訂版，但遊戲還是原欄位的舊文字 |
| 文字不符 | 頁面或文字資料裡找到相似的句子但內容不同。紅底 = Excel 有、遊戲沒有；黃底 = 遊戲多出或不同的文字 |
| 需看圖確認 | 圖片 OCR 讀到的字和 Excel 不完全一樣。OCR 常認錯字（例如 Game 認成 Came），所以不直接算錯誤，請看縮圖判斷 |
| 空白/標點差異 | 字都一樣，只有空白、引號或全形/半形標點不同 |
| Excel 未列出 | 遊戲裡有這句，但 Excel 沒有對應的答案 |
| 遊戲找不到 | Excel 有這句，但遊戲裡沒有相似的文字（尚未上版，或 OCR 認不出來） |

### 關於圖片 OCR

- 第一次使用會從 `cdn.jsdelivr.net` 下載辨識元件與各語言模型，之後會快取。每種語言約 10–30 秒，15 種語言約 3 分鐘。
- 每張字圖會用兩種前處理各辨識一次，比對時取較接近 Excel 的結果。`[WILD]` 這類佔位符的位置允許任何雜字（圖示常被認成亂碼）。
- 圖片文字比對時不分大小寫、忽略空白，並把 OCR 容易混淆的字視為相同（l/I/1、O/0、長得一樣的西里爾與拉丁字母）。
- OCR 認錯的字請到「全部字句」分頁修正；修正只存在這次的畫面，重新整理網頁會消失（匯出的報告會包含修正後的文字）。

其他提示：

- **Excel 內疑似重複字**：例如泰文「จะจะ」，代表翻譯表本身可能打錯。
- **只有數字的千分位符號不同**：例如 Excel 是 `2.000`、頁面是 `2,000`。
- **頁面上的其他文字**：頁面上有、但 Excel 沒列出的文字，僅供參考（Excel 通常只列這次要確認的字串）。
- **相似度門檻**：越高越嚴格，低於門檻的會歸為「頁面找不到」。

## 設定

- `PORT`：伺服器埠號，預設 `5178`
- `HOST`：預設 `127.0.0.1`（只有本機能開）；設成 `0.0.0.0` 可讓同網段的同事連入（`start-share.bat` 就是這樣做）
- `ALLOW_HOSTS`：代理可讀取的網域，逗號分隔，預設 `object1.net`（含所有子網域）

遊戲伺服器沒有開放跨網域讀取，所以頁面一律透過本機伺服器的 `/api/proxy` 讀取，而代理只會連到 `ALLOW_HOSTS` 裡的網域。
